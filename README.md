# 🏆 Training Arena · 訓練競技場

把訓練課程的成績表變成一個會動、會歡呼、會讓學員想往上爬的**互動排位榜**。

三個維度 —— 品質成績、上課表現、考試成績 —— 合成一個「總戰力」，17 位學員即時排名。
資料放在 Google 試算表，你在試算表改分數，排行榜按一下同步就當場重新洗牌。

---

## 快速開始

直接用瀏覽器打開 `index.html` 就會跑起來（第一次會自動載入 17 人示範資料）。
要放給學員用手機看，把整個資料夾丟上 GitHub Pages 或任何靜態空間即可 —— 沒有任何相依套件、不需要伺服器。

---

## 接上你的 Google 試算表

1. 開一份新的 Google 試算表，**第一列**填欄位名稱：

   | 姓名 | 組別 | 頭像 | 品質成績 | 上課表現 | 考試成績 |
   |------|------|------|----------|----------|----------|
   | 陳彥廷 | 雷霆隊 | 🦊 | 88 | 92 | 85 |
   | 林佳蓉 | 疾風隊 | 🐯 | 95 | 88 | 91 |

   - **姓名**：必填，也是每位學員的身分依據
   - **組別**：填了才會出現「隊伍戰」分頁；留空就只跑個人榜
   - **頭像**：一個 emoji；留空會自動配一隻動物
   - **三項成績**：0–100 的數字，超出範圍會自動夾回區間

2. 右上角「共用」→ 一般存取權改成 **「知道連結的任何人」→ 檢視者**。
   （這步沒做，網頁讀不到資料。）

3. 複製瀏覽器網址列的整段連結，貼到網頁的「設定 → Google 試算表連動」，按 **儲存並同步**。

欄位名稱有做模糊比對，寫「品質」「表現」「考試」或英文 `quality` / `performance` / `exam` 都認得。
分頁名稱留空就讀第一個分頁；有多個分頁時填上分頁名。

## 四個模式

| 模式 | 做什麼 |
|------|--------|
| **個人榜** | 主畫面。前三名頒獎台 + 17 人排位列，名次變動時卡片會實體滑動超車 |
| **隊伍戰** | 依「組別」自動分組，隊伍分數 = 組內平均戰力 |
| **個人戰績卡** | 點任一位學員 → 能力三角雷達圖、名次走勢、徽章牆、生涯最佳名次 |
| **頒獎典禮** | 全螢幕，從最後一名倒數揭曉到第一名。前三名放慢節奏、冠軍噴彩帶配樂 |

---

## 戰力怎麼算

```
總戰力 = 品質成績 × 權重 + 上課表現 × 權重 + 考試成績 × 權重
```

預設 30% / 30% / 40%，在「設定 → 戰力權重」用滑桿即時調整，
三項會自動正規化成總和 100%，**拉動滑桿排行榜就當場重排** —— 這本身就是很好用的教學演示。

段位依總戰力分成：青銅 → 白銀 → 黃金 → 白金 → 鑽石 → 王者。

## 徽章

| 徽章 | 解鎖條件 |
|------|----------|
| 🚀 進步之星 | 與上一回合相比，名次進步最多的人 |
| 🔥 連霸 | 連續兩回合排名第一 |
| ✨ 品質達人 | 全班品質成績最高 |
| 🙋 課堂之星 | 全班上課表現最高 |
| 🎯 考神 | 全班考試成績最高 |
| 💯 滿分王 | 任一項拿到 100 |
| ⚖️ 三維均衡 | 三項成績差距在 5 分以內 |
| ⚡ 火力全開 | 總戰力 90 以上 |

設計上刻意讓「非第一名」也有東西可拿 —— 進步之星、三維均衡、單項王都跟總排名無關，
避免只有前幾名有參與感。

## 賽季回合

「進步之星」和名次走勢圖需要有比較基準，所以按 **存檔回合**（快捷鍵 `S`）會把當下的名次記錄成一個回合。

建議的節奏：每上完一個單元、或每週結束時存一次檔。存兩個回合以上，個人戰績卡就會出現名次走勢折線。

回合紀錄存在瀏覽器的 localStorage，**換電腦或清瀏覽器資料就會不見** ——
重要的話用「設定 → 匯出備份 JSON」存成檔案。

## 鍵盤快捷鍵

| 鍵 | 動作 |
|----|------|
| `R` | 同步試算表 |
| `S` | 存檔本回合 |
| `C` | 開啟頒獎典禮 |
| `1` `2` `3` | 切換個人榜 / 隊伍戰 / 設定 |
| `Esc` | 關閉戰績卡或離開頒獎典禮 |

頒獎典禮中：`空白鍵` / `→` 揭曉下一位、`←` 回上一位、`Esc` 離開。

---

## 上課時好用的幾個開關

- **隱藏分數**（設定 → 顯示）：只顯示名次不顯示分數。想公開排名但不想公開實際成績時用。
- **自動同步**：每 60 秒重讀試算表。投影在教室螢幕上，你在手機改分數，畫面自己更新。
- **關閉動畫**：投影機效能不好時可以關掉粒子與換位動畫。

## 檔案結構

```

css/style.css       電競霓虹暗色主題、所有動畫
js/data.js          狀態儲存、Google 試算表讀取與 CSV 解析、戰力與徽章計算
js/effects.js       背景粒子、彩帶、數字滾動、FLIP 換位、WebAudio 音效
js/ui.js            排行榜 / 頒獎台 / 隊伍 / 個人戰績卡渲染
js/ceremony.js      頒獎典禮揭曉流程
js/app.js           啟動與事件綁定
sample-data.csv     可直接匯入 Google 試算表的範本
```

無相依套件、無建置步驟。所有動畫都是原生 CSS / Web Animations API / Canvas。
